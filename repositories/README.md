# GitHub-ready source mirror

The `CppStudio/` subfolder is a complete, clean copy of the Android Studio project at **C++ Studio 1.4** (version code 24). It includes the offline example catalogue, variant-aware analysis, the existing 1.3.x Ignore/Restore and indentation improvements, and the verified offline compiler installer.

To publish it as a GitHub repository, create an empty repository on GitHub and upload the **contents of `repositories/CppStudio/`** as the repository root. It includes the Gradle wrapper, application source, resources, manifest, and README.

The project at the parent folder is the working copy. Keep this mirror refreshed when you make additional source changes.
